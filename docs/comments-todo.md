# 评论功能现状与待办（2026-10-24）

实现见 apps/web/components/comments.tsx、comment-form.tsx、comments.css；说明见 AGENTS.md 对应条目。

## 已知缺陷 / 未做
- 不显示图片：评论正文只放行段落、链接、加粗、代码、引用、列表；`![](url)` 会被去掉。Shiro 会直接显示外链图片（无上传功能）。可选方案：① 与 Shiro 一致放行 https 图片并限宽、懒加载；② 显示为“查看图片”链接，点击才加载（避免陌生地址拿到读者 IP）。
- ~~不支持读者登录评论~~：2026-10-24 已支持 GitHub 读者登录（c513f22），尚未用真实 GitHub 账号发过读者评论。
- 不支持编辑评论。
- 不分页：只取最新 10 条主评论，超过时仅提示“只显示最新的 10 条评论”。
- 回复过多时 Core 会折叠中间部分，前端只提示“还有 N 条回复暂未显示”，不能展开（Core 有 /comments/thread/:id 可用）。
- 不在本地保存访客昵称/邮箱/网址，依赖浏览器自动填充。
- ~~提交成功后不立即显示新评论~~：2026-10-26 已改为提交成功后 updateTag 刷新（f5bbc52）；后台“审核通过”“置顶”Core 仍不发事件，最多等 1 分钟。
- 访客不知道博主是否开启审核（Core 不公开该设置），成功提示只能笼统说明“开启审核时通过后才显示”。
- 成功路径只用协议替身验证过，未在隔离库真实写入评论。
