# 设计方向调研（2026-10-26，待用户选定）

目标：做出自己的风格。Innei（innei.in，Shiro 作者）是用户的偶像，可以学他“为什么好看”，但不能照搬他的外观。

## Innei 的博客为什么好看

在 1920×991 下实际看了首页、文章列表、文章详情和手记，并读取了页面的实际样式：

1. **一个统一的氛围主题**：纸张纹理背景（`#fefdfa`）、飘落的叶子、“随季节写作”的时间轴，手记还标着季节。整站讲的是同一个故事。
2. **只有一个强调色**：暖橙 `#aa5e26`，只用在当前导航（手写感的弧形下划线）、置顶、翻译标签、链接上。其余全是暖灰。
3. **字体有分工**：界面和文章用无衬线（正文 16px / 行高 28px，标题 700 粗）；手记正文和小节标题用 Georgia + 思源宋体；栏目名用加宽字距的小号大写（如 “BLOG”）。
4. **有记忆点的细节**：手记卡片首字下沉、深色题图加波形装饰、列表编号 01/02、相对时间、右栏阅读进度百分比。
5. **形状柔和**：圆角卡片、柔和阴影、大量留白。

**结论：不能用的**是他的标志物：纸张纹理、飘落装饰、暖橙强调色、弧形下划线、首字下沉、圆角柔和卡片。
上一轮的“暖纸”配色（米白底 + 朱砂）和他的配色非常接近，应当淘汰。
**可以学的**是原则：一个氛围主题贯穿全站、只用一个强调色、字体分工明确、少量有记忆点的细节。

| base-ui.com | 瑞士式极简：浅灰底、纯黑字、无衬线、大量留白、方形色块 | 我们现在的直角细线就源自这里；排版靠网格和对齐，不靠装饰 |
| antfu.me | 单色极简：白底、灰色次要文字、没有强调色 | 克制；栏目切换只用文字明暗区分 |

## 建议的方向：「排版工作台」

推荐**以瑞士排版为骨架，再借新粗野主义的按下手感**。理由有三：
- 现在的三栏 + 1px 分隔线 + 直角硬投影本来就是这条路。
- 这条路和 Innei 的暖纸柔和路线正好相反，天然不会撞车。
- 它是靠规则（网格、字号阶梯、对齐）建起来的，最适合写成设计系统。

氛围主题：**“写作者的工作台 / 排版稿”**，讲究对齐、编号、标注，像一份认真排过版的稿件。

| 维度 | 我们的做法 | 与 Innei 的区别 |
| --- | --- | --- |
| 底色 | 中性白 / 近黑，不加纹理 | 他是暖纸 + 纹理 |
| 强调色 | 一个冷色（候选：克莱因蓝 `#0038b8`），只用在链接、当前项、主按钮 | 他是暖橙 |
| 当前项 | 实心色块反白，或 2px 直线下划线 | 他是弧形手写下划线 |
| 字体分工 | 界面和文章用无衬线；手记用衬线；**日期、编号、阅读数等元信息统一用等宽字体**（标志点） | 他的元信息用小号无衬线 |
| 形状 | 直角、1px 实线、硬投影 | 他是圆角 + 柔和阴影 |
| 交互手感 | 按钮、标签按下时硬投影收回、元素位移 2px（标志点） | 他偏淡入淡出 |
| 手记 | 衬线正文，和文章同底色；用等宽大号日期和左侧竖线标出“日记感” | 他用纸张卡片、首字下沉、深色题图 |
| 装饰 | 不做背景动画；用编号、标注线、网格对齐营造秩序感 | 他用飘落叶子 |

备选方向：**纯新粗野**（米灰底、黑色粗描边、高饱和色块），更活泼更有个性，但长文阅读容易累，适合作品页、不太适合博客全站。

## 选定方向后的落地顺序

1. 定变量：字号阶梯（草案 12/14/16/20/24/32px）、间距阶梯（4px 基数：4/8/12/16/24/32/48）、行高（正文 1.75、标题 1.3）、颜色（中性色阶 + 一个强调色 + 语义色）、动效（120ms/180ms）。
2. 统一基础组件：按钮、输入框、标签、链接、分页、元信息行，以及空、加载、失败状态；每个组件写清默认、悬停、按下、焦点、禁用。
3. 统一正文排版：Markdown 与 Haklex 富文本对齐同一套规则。
4. 整理页面模式（列表、详情、右栏、手机），把 `/debug` 做成样式指南页。
