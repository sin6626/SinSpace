# 设计方向调研（2026-10-26，待用户选定）

目标：做出自己的风格。Innei（innei.in，Shiro 作者）是用户的偶像，可以学他“为什么好看”，但不能照搬他的外观。

## Innei 的博客为什么好看

在 1920×991 下实际看了首页、文章列表、文章详情和手记，并读取了页面的实际样式：

1. **一个统一的氛围主题**：纸张纹理背景（`#fefdfa`）、飘落的叶子、“随季节写作”的时间轴，手记还标着季节。整站讲的是同一个故事。
2. **只有一个强调色**：暖橙 `#aa5e26`，只用在当前导航（手写感的弧形下划线）、置顶、翻译标签、链接上。其余全是暖灰。
3. **字体有分工**：界面和文章用无衬线（正文 16px / 行高 28px，标题 700 粗）；手记正文和小节标题用 Georgia + 思源宋体；栏目名用加宽字距的小号大写（如 “BLOG”）。
4. **有记忆点的细节**：手记卡片首字下沉、深色题图加波形装饰、列表编号 01/02、相对时间、右栏阅读进度百分比。
5. **形状柔和**：圆角卡片、柔和阴影、大量留白。

**结论：不能用的**是他的标志物：纸张纹理、飘落装饰、暖橙强调色、弧形下划线、首字下沉、圆角柔和卡片。
上一轮的“暖纸”配色（米白底 + 朱砂）和他的配色非常接近，应当淘汰。
**可以学的**是原则：一个氛围主题贯穿全站、只用一个强调色、字体分工明确、少量有记忆点的细节。

## 定稿：「熄灯以后」（2026-10-26 拷问共识）

“排版工作台”和克莱因蓝被否掉。用户要的是**我的 space**：作品集、博客、心里话、平日里的快乐都放在这里。

### 核心画面

用户的真实经历：每天 10 点半回寝室，洗漱洗衣后就要睡；大一常看算法题到 12 点熄灯才停，停下来时喜欢去**阳台看外面的星星**。
核心画面 = **熄灯后，宿舍阳台，抬头看月亮和星星**。

### 决定清单

| # | 问题 | 决定 |
| --- | --- | --- |
| 1 | 核心画面 | 熄灯后的宿舍阳台，夜空、月亮、星星 |
| 2 | 场景强度 | 首页完整场景；内页克制，只在顶部留一点星点，正文干净 |
| 3 | 主题 | 默认熄灯（深色）。切换器文字改为“开灯 / 熄灯 / 跟随系统”。浅色 = 开着灯的寝室 |
| 4 | 四个角落 | 作品 → 作品；博客 → 文章；心里话 → 手记；日常快乐 → 速记，改名**碎碎念**，提到一级导航。时间线、友链、一言收进“更多” |
| 5 | 首页结构 | 首屏全宽阳台场景，往下滚“回屋里” |
| 6 | 全站布局 | 去掉三栏。顶部导航 + 单栏居中（48rem）；目录悬浮在正文右侧留白（窄屏隐藏）；搜索和标签放到列表页顶部；订阅放页脚；在线人数和开关灯放导航右侧；删掉拖动栏宽组件 |
| 7 | 形状 | 不再用直角、实线、硬投影（那是 Base UI 官网样式）。整体柔和，圆角和直角配合，投影改为粉紫柔光 |
| 8 | 圆角规则 | 能摸到的东西用圆角：按钮、输入框、分页 6px；标签、开关做成胶囊；卡片、弹层、Toast、下拉菜单 12px + 柔光；头像圆形；正文图片、代码块、引用 6px。结构性的东西（页面分区、导航条、页脚、列表间隔）直角、不画线，靠留白和淡底色分隔；必须画线时用很淡的半透明线 |
| 9 | 字体 | 无衬线用系统字体（英文 Geist，中文苹方 / 微软雅黑），文章标题也用无衬线（用户觉得无衬线更柔和）。**衬线只用于手记**的标题和正文，加载思源宋体网络字体（按字切片），只在手记页加载 |
| 10 | 首页下半部分 | 四个角落各放几条最新内容，顺序：碎碎念、手记、文章、作品 |
| 11 | 自我介绍 | 紧接在场景下面：圆形头像、名字、个人介绍一句话、“更多关于我 →”链接到“关于我”页面；全部读后台个人资料 |
| 12 | 首屏那句话 | 读后台“站点描述”，已改为“夜深里也有月亮和星星陪我作伴” |
| 13 | 月亮 | 跟着真实月相变化（按访问当天日期计算，SVG 绘制）；新月时留一圈很淡的轮廓 |
| 14 | 站名 | 后台站点标题已改为“Sin’s Space”。前端改为读后台，不再写死 |
| 15 | 浅色场景 | 同一个阳台的黄昏：淡粉紫晚霞，月亮淡淡挂着，几颗刚冒出的星星 |
| 16 | 动效 | 只在首页场景里动：星星缓慢闪烁，每 20～40 秒随机一颗流星，月亮不动。“减少动态效果”时全部静止，场景不可见时暂停。开关灯时天色做约 0.6 秒的渐变过渡 |
| 17 | 内页星点 | 顶部约 200px 高的渐隐夜空带，零星几颗静止星星，页面标题压在上面；浅色是淡晚霞 |
| 18 | 手机 | 菜单按钮 + 全屏夜空菜单（开关灯在菜单底部）；首页场景同样占满第一屏 |
| 19 | 列表形态 | 四个角落各有形态：作品是卡片网格；文章是标题 + 摘要列表；手记是日记样式（衬线标题、大号日期、心情天气、正文开头几行）；碎碎念是完整显示的小卡片 |
| 20 | 后台 | 不动，保持 mx-admin 原样；以后需要再只换主题色 |
| 21 | 推进方式 | 本地分支 `feat/night-space`，分 5 步，每步用户在浏览器看过再继续，每步单独提交；全部完成后由用户决定是否合并 main |

视觉元素（夜空、月亮、栏杆剪影、星星、图标）由 Agent 用 CSS / SVG 自己画（个人项目，没有 UI 配合）。用户本人的照片等真实素材才找用户要。
