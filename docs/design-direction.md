# 设计方向调研（2026-10-26，待用户选定）

目标：做出自己的风格。Innei（innei.in，Shiro 作者）是用户的偶像，可以学他“为什么好看”，但不能照搬他的外观。

## Innei 的博客为什么好看

在 1920×991 下实际看了首页、文章列表、文章详情和手记，并读取了页面的实际样式：

1. **一个统一的氛围主题**：纸张纹理背景（`#fefdfa`）、飘落的叶子、“随季节写作”的时间轴，手记还标着季节。整站讲的是同一个故事。
2. **只有一个强调色**：暖橙 `#aa5e26`，只用在当前导航（手写感的弧形下划线）、置顶、翻译标签、链接上。其余全是暖灰。
3. **字体有分工**：界面和文章用无衬线（正文 16px / 行高 28px，标题 700 粗）；手记正文和小节标题用 Georgia + 思源宋体；栏目名用加宽字距的小号大写（如 “BLOG”）。
4. **有记忆点的细节**：手记卡片首字下沉、深色题图加波形装饰、列表编号 01/02、相对时间、右栏阅读进度百分比。
5. **形状柔和**：圆角卡片、柔和阴影、大量留白。

**结论：不能用的**是他的标志物：纸张纹理、飘落装饰、暖橙强调色、弧形下划线、首字下沉、圆角柔和卡片。
上一轮的“暖纸”配色（米白底 + 朱砂）和他的配色非常接近，应当淘汰。
**可以学的**是原则：一个氛围主题贯穿全站、只用一个强调色、字体分工明确、少量有记忆点的细节。

## 用户的决定（2026-10-26）

“排版工作台”和克莱因蓝都被否掉了。用户的原话意思是：这个网站是**我的 space**，作品集、博客、内心想说的话、平日里的快乐都放在这里，它的面貌不该是工作台。

问答结果：
- 整体感觉：**夜晚星空**（默认偏深色，安静又有点浪漫，像夜里一个人的空间）。
- 颜色：**柔和的粉紫**。
- 个人符号：**一个喜欢的地方或时刻**（具体是哪里、哪个时刻还没说）。
- 之前已定：保留直角硬投影、手记用衬线体。

## 当前方案：「夜空」配色（草案）

| 变量 | 深色（主场：夜里） | 浅色（黎明前） |
| --- | --- | --- |
| 背景 | `#110e1b` 紫黑夜空 | `#fbf8fd` 淡紫白 |
| 文字 | `#ece8f4` | `#231d33` |
| 次要文字 | `#a59fb8` | `#6b6280` |
| 边框 | `#2c2640` | `#e6def0` |
| 强调色 | `#e0a6e8` 柔粉紫 | `#9b4f96` 深兰紫（保证对比度 ≥ 4.5） |
| 硬投影 | 粉紫 22% | 兰紫 20% |

在 `/debug` 顶部切到“夜空”查看；“靛蓝”“暖纸”已删除，“墨”保留作对照。

## 只靠颜色还不够

只换颜色，页面会显得是“紫色的普通博客”，夜空的感觉需要**画面素材**：星空背景、那个“喜欢的地方或时刻”的照片或插画、导航或首页的小图标。按用户规则这些不能用 CSS/SVG 硬画，需要用户提供素材（或找 UI 出图）。

## 之后的落地顺序

1. 用户补充“喜欢的地方或时刻”，并决定素材来源。
2. 定变量：字号阶梯、间距阶梯（4px 基数）、行高、颜色阶梯、动效。
3. 统一基础组件：按钮、输入框、标签、链接、分页、元信息行，以及空、加载、失败状态。
4. 统一正文排版（Markdown 与 Haklex）。
5. 按 space 的四个角落（作品、博客、心里话、日常快乐）整理页面模式，`/debug` 做成样式指南页。
