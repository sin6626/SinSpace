## 组件与动画依赖

### Base UI 为主，样式自己设计

2026-10-22 用户调整了组件方向：直接以 Base UI 为交互基础，样式由项目设计，不采用 shadcn/ui 的默认外观。Base UI 是无样式组件库，可以使用现有 Tailwind CSS 或普通 CSS 定义样式，已安装 `@base-ui/react` 1.9.0，导航使用 Navigation Menu。[Base UI 样式说明](https://base-ui.com/react/handbook/styling)

各层的职责是：

| 层 | 职责 | 本项目的使用方式 |
| --- | --- | --- |
| Base UI | 提供底层交互与无障碍能力，例如弹窗焦点管理 | 保留其正确行为，不为外观重写基础交互 |
| Tailwind 与设计变量 | 定义组件在本项目中的外观 | 自己设计颜色、间距、尺寸和状态样式，不把示例 CSS 当成默认主题 |
| shadcn/ui（可选） | 提供可以参考或选用的现成组件实现 | 只有确实合适时才引入，核对依赖和基础库，并适配本站样式；不默认初始化整套体系 |
| 业务组件 | 表达文章条目、作品信息等业务内容 | 在出现实际复用需求时组合，不预建通用框架 |

Base UI 负责组件行为，但不会替项目决定视觉风格；自行添加样式后仍需检查焦点、对比度和可访问名称。状态样式优先使用组件提供的状态参数或 `data-*` 属性，不再维护一份重复的“是否打开／是否选中”状态。[Base UI 入门](https://base-ui.com/react/overview/quick-start)

使用顺序为“原生语义 HTML 能满足则直接使用 → 有交互需求时使用 Base UI 并自行写样式 → 有适合的 shadcn 现成实现时再按需选用”。没有现成组件时先判断需求是否必要，不为了补齐组件目录自行造一套 UI 库。

检查方法：确认组件来源、交互能力和依赖，说明哪些样式属于本站；修改后检查键盘、焦点、状态和样式，不能只检查截图。

### Motion 与 GSAP

业务动效默认使用 Motion for React。当前尚未安装。导航的基础开合和尺寸过渡采用 Base UI 官方状态属性与 CSS transition，避免两套动画机制控制相同属性。GSAP 只在出现明确的复杂时间线、滚动联动或精细编排需求后单独评估，不提前加入依赖。[Motion 官方文档](https://motion.dev/docs/react)

保留组件自带的基本状态过渡。同一元素的同一属性由一个动画机制控制。动效必须能被打断，不能依赖播放完毕才能操作。具体规范见[动效与无障碍](./design-system.md#8-动效规范)。

### 数据请求与状态

公开 API 使用本地 workspace SDK `@mx-space/api-client`，客户端模块基于其原生 fetch 适配器设置超时与 Next 缓存规则；接口地址单独读取环境配置。组件内交互使用 React 自身状态能力。暂不引入全局状态库、额外请求缓存库或新的接口代理层。

公开读取现使用 `apps/web/lib/blog-data.ts` 的 `use cache`、`cacheLife` 与标签，时间与范围见[缓存说明](./cache-and-layout.md)。不能把鉴权内容按公开内容缓存。接口字段、枚举、分页和错误格式以 Mix Space 当前源码及文档为准，缺失时先明确问题，不猜测 DTO。

## Spectrum 的使用边界

参考 Spectrum 的原则、设计变量、排版层级、布局和组件使用指导。网站视觉由用户设计，不引入 Adobe 的组件库，不复制 Adobe 字体或品牌色，也不把企业工具的全部组件范围搬进博客。[Spectrum](https://spectrum.adobe.com/)

本项目的三层变量结构是自己的组织方式，不声称与 Spectrum 内部数据格式完全一致。变量由本站维护，Base UI 不要求使用 shadcn 的变量名。当前文档已有的通用语义名称可以保留；按需采用外部组件时，把其样式接到本站变量，而不是让外部组件反过来决定设计系统。

## 依赖与变更规则

- 现有依赖、标准能力和已选组件能解决时，不增加新包。
- 引入依赖前先说明实际需求、职责、替代方案和维护影响，再在用户确认的学习单元中实施。
- 安装时记录实际版本并更新对应锁文件，不因示例使用 `latest` 就长期依赖浮动版本。
- 新项目使用一个 pnpm workspace 与锁文件管理前后端和 SDK。旧项目仍独立保留；不复制其依赖或数据目录。
- 仅按实际交互需求引入依赖。目前已引入 react-resizable-panels 和 Base UI；未安装 shadcn/ui、Motion 或 GSAP。
